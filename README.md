# 안심드라이브 모바일 프로토타입

아이폰 15 Pro 브라우저에서 앱처럼 확인하는 가족 안심 운전 모니터링 서비스 프로토타입입니다.

## 구성

- 홈: 안심 점수, 현재 위치, 위험 운전 요약
- 리포트: 주간 운전 점수, AI 분석 메모, 가족 대화 제안
- 알림: 급감속, 과속, 안전 귀가 이벤트 타임라인
- 혜택: 보험사 UBI 리포트, 지자체 바우처 연계

## 실행

정적 파일이라 브라우저에서 바로 열 수 있습니다.

```bash
python3 -m http.server 8000
```

그 뒤 `http://localhost:8000`으로 접속하면 됩니다.
